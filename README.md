# 갈피 (Loreleaf)

모바일에서 장편을 쓰는 앱. 글은 사용자가 쓰고, 설정은 갈피가 기억한다.

> 강력한 기능을 제공하면서도 강력해 보이지 않게 만들어라.

## 실행

```bash
npm start
```

- PC: http://localhost:5173
- 휴대폰: 같은 와이파이에서 터미널에 찍히는 `http://192.168.x.x:5173` 주소로 접속
- 빌드 과정 없음. Node만 있으면 된다 (의존성 0개). 정적 파일이라 어떤 웹 호스팅에 올려도 동작하고, HTTPS로 올리면 홈 화면에 앱처럼 설치된다.

## 설계 메모

**형광펜은 원고에 들어가지 않는다.** 에디터는 평범한 `textarea`이고, 그 뒤에 같은 글자를 투명하게 그린 레이어를 깔아 이름 부분만 배경색을 칠한다. 원고 데이터는 순수 텍스트 그대로다. 한글 입력(IME)이 가장 안정적인 방식이기도 하다.

**데이터베이스 느낌 없이.** 저장 버튼 없음, 이름 비우고 나가면 빈 항목은 조용히 사라짐, 폴더를 지워도 내용은 밖으로 꺼내질 뿐, 삭제는 확인창 대신 "되돌리기".

**화면엔 지금 필요한 것만.** 에디터 상단바는 쓰기 시작하면 흐려진다. 설정 카드는 모달이 아니라서 쓰던 흐름을 막지 않는다. "캐릭터로 등록" 버튼은 단어를 선택했을 때만 나타난다.

**저장.** 모든 데이터는 브라우저 IndexedDB. 입력 중인 본문은 localStorage에도 즉시 남겨서, 저장 직전에 앱이 꺼져도 다음 실행 때 복구한다.

## 다음 단계 (아직 안 넣음)

핵심 흐름을 실제로 써보면서 다듬은 다음에 붙인다.

- **관계도** — 캐릭터 설정 화면 안에 "관계" 섹션으로. 데이터는 `relations: [{ from, to, history: [{ chapterId, label }] }]` 형태로 따로 저장해서, "3화: 동료 → 12화: 적대"처럼 화 기준으로 변화를 기록.
- **상태 기록** — 지금의 설정 항목(`fields`)에 `history: [{ chapterId, value }]`를 덧붙이는 방식. 기본은 지금처럼 값 하나만 보이고, 필요한 사람만 "몇 화부터 바뀜"을 추가. 설정 카드는 **지금 보고 있는 화 시점의 값**을 보여주게 된다.
- 에디터 글꼴/크기 설정, 화 드래그 정렬, 안드로이드 뒤로 가기로 시트 닫기.
