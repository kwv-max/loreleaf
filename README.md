# 갈피 (Loreleaf)

모바일에서 장편을 쓰는 앱. 글은 사용자가 쓰고, 설정은 갈피가 기억한다.

> 강력한 기능을 제공하면서도 강력해 보이지 않게 만들어라.

## 실행

```bash
npm start
```

- PC: http://localhost:5173
- 안드로이드 폰(빠르게 보기): 같은 와이파이에서 터미널에 찍히는 `http://192.168.x.x:5173` 주소를 크롬으로 연다.
- 안드로이드 폰(앱처럼 설치): 폰의 USB 디버깅을 켜고 PC와 USB로 연결 → PC 크롬 `chrome://inspect/#devices` → Port forwarding에 `5173 → localhost:5173` 추가 → 폰 크롬에서 `http://localhost:5173` → 메뉴의 "홈 화면에 추가". localhost는 보안 주소로 취급되어 설치·오프라인이 동작한다. (나중엔 HTTPS 호스팅에 올리면 USB 없이 설치 가능)
- 빌드 과정 없음. Node만 있으면 된다 (의존성 0개).
- 아이폰(사파리): 사파리로 열고 공유 → "홈 화면에 추가". 맥이나 따로 빌드는 필요 없다. 다만 아이폰은 USB 포트 포워딩으로 localhost를 쓸 수 없어서, 오프라인·설치까지 제대로 되려면 HTTPS 주소(호스팅)에 올려야 한다.
- 대상 플랫폼은 안드로이드(크롬)가 먼저, 아이폰(사파리 홈 화면 앱)도 지원한다. 아이폰에는 뒤로 가기 버튼이 없으니 화면마다 위쪽 뒤로 버튼이 늘 있어야 한다.

## 설계 메모

**형광펜은 원고에 들어가지 않는다.** 에디터는 평범한 `textarea`이고, 그 뒤에 같은 글자를 투명하게 그린 레이어를 깔아 이름 부분만 배경색을 칠한다. 원고 데이터는 순수 텍스트 그대로다. 한글 입력(IME)이 가장 안정적인 방식이기도 하다.

**데이터베이스 느낌 없이.** 저장 버튼 없음, 이름 비우고 나가면 빈 항목은 조용히 사라짐, 폴더를 지워도 내용은 밖으로 꺼내질 뿐, 삭제는 확인창 대신 "되돌리기".

**화면엔 지금 필요한 것만.** 에디터 상단바는 쓰기 시작하면 흐려진다. 설정 카드는 모달이 아니라서 쓰던 흐름을 막지 않는다. "캐릭터로 등록" 버튼은 단어를 선택했을 때만 나타난다.

**대사 줄.** 따옴표는 원고 글자가 아니라 `chapter.quotes = { 줄번호: 'd' | 's' }` 표시로 저장한다. 글을 고칠 때마다 바뀐 구간을 찾아 표시를 제 줄로 옮긴다 (`remapFlags`). 따옴표를 글자로 쓰던 예전 원고는 처음 열 때 한 번 변환된다.

**안드로이드 뒤로 가기.** 시트·설정 카드·찾기 막대가 떠 있으면 뒤로 가기는 화면을 넘기지 않고 그것부터 닫는다 (`interceptBack`). 앱을 다시 열어 깊은 화면이 복구되면 상위 화면들을 기록에 깔아 두어, 뒤로 가기가 앱을 끄지 않고 목록으로 올라간다 (`seedHistory`).

**화마다 바뀌는 설정.** 설정 항목은 처음 값 `value`와 `changes: [{ chapterId, value }]`를 가진다. 어떤 화 시점의 값은 그 화까지의 기록 중 가장 늦은 것 (`valueAt`). 화 순서를 바꾸면 기록도 새 순서를 따른다.

**설정끼리 연결.** 값은 자유 글로 두고, 연결된 목록의 이름이 나오면 본문 형광펜과 같은 방식으로 알아본다 (`linkParts`). `field.link`는 목록 종류, `null`이면 연결 끔, 없으면 항목 이름으로 기본값(현재 위치 → 장소 등). 반대 방향 '연결된 곳'은 저장하지 않고 그때그때 찾는다 (`mentionsOf`) — 값을 고치면 연결도 저절로 바뀐다.

**주석.** `chapter.notes = [{ id, start, end, text }]`. 글이 바뀔 때 대사 줄 표시와 같은 방식으로 바뀐 구간을 찾아 위치를 옮긴다 (`remapRange`). 달린 글이 다 지워지면 길이 0으로 남아 '지워진 글'로 표시된다.

**저장.** 모든 데이터는 브라우저 IndexedDB. 입력 중인 본문은 localStorage에도 즉시 남겨서, 저장 직전에 앱이 꺼져도 다음 실행 때 복구한다.

## 다음 단계 (아직 안 넣음)

핵심 흐름을 실제로 써보면서 다듬은 다음에 붙인다.

- 에디터 글꼴/크기 설정, 화 드래그 정렬, 찾아 바꾸기.
